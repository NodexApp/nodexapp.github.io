In development

3 added10 changed10 fixed

Added3

  • Set anything in your Inbox aside with **Later** when it can wait. Choose a time and the message or the work waiting on you leaves your Inbox, then comes back with a notification when that time arrives; if it needs you for a new reason before then, it shows at once. The new Later view lists everything you set aside in the order it returns, and Nodex can suggest Later for a message that says when the work should wait until. It works on the phone too.
  • Save a thought that asks for no work with **Save to Notes**. Each Project, and the Inbox itself, gets a Notes page; a saved message becomes a page beneath it, off the Board, where you can arrange notes into sections. Nodex suggests it for references and can file a note under a section you already have.
  • Agents can set properties on many Pages in one step. Ask a chat to mark a batch of cards Done or re-prioritize a Board and it commits the whole change together and reports each card's resulting values, instead of editing cards one at a time. On the command line, nodex page properties set NODEX-4 NODEX-8 --set Status=done --set Priority=p1-high does the same, nodex page create takes --set, and nodex page move moves several Pages at once.

Changed10

  • The Inbox and the Board now agree about every message. A message waits in your Inbox while its card is in Triage and yours to decide, so moving the card on the Board handles it, and moving it back to Triage brings it back. **Keep** is now **Add to Todo**, and a card appears in the Inbox once, whether it waits to be routed or needs your answer or review. In a shared Space, each person's Inbox shows the messages they own.
  • Stable updates reach you sooner with the same build already tested on Nightly. Both channels show app versions as x.y.z, and you can choose your channel in Settings.
  • Opening N more properties on a Page now lists its empty properties by name instead of a column of rows that say Empty. Choose one and it joins the list with its editor already open, and it stays there while the Page is open. Hidden properties that hold a value still open as rows.
  • The built-in Parent property is now called **Part of**, so a Page under another reads "Part of" followed by that Page. A property you renamed keeps your name. Part of and Waits for also have their own icons.
  • Clicking an image in a Page's Files, or an image attachment in its body, now shows it over the Page instead of opening a tab. Step through the Page's images with the arrow keys, and choose **Open in tab** when you want to keep one open; Cmd/Ctrl-click still opens the tab directly.
  • Nodex tells you when a chat finishes while you are reading another one. Turn completion notifications used to stay silent whenever a Nodex window was focused, so an Automation's run or a second chat could finish unnoticed. Now only the chat in front of you stays quiet by default. Settings offers this as **When the chat isn't in view**; choose **When Nodex is in the background** to keep banners away while a Nodex window is focused.
  • Heartbeat chats read like conversations. A heartbeat's message shows its instructions and names the Automation that sent it, and the Agent's reply shows what it wrote, without the surrounding markup. Checks that found nothing to report fold into a single **Quiet check** line, and a run of them shares one line with their count and latest result; expand it to see any check in full.
  • Agents run nodex directly in their shells. Nodex resolves who is asking each time the command runs, so a script an Agent wrote in an earlier turn keeps working after Nodex restarts, and its changes stay credited to the chat that made them. nodex context shows who the command is acting as and which Space and Project it targets, and a refused command says why and what to do next.
  • A retry key can be any text up to 128 characters, in chats and with --idempotency-key. Reuse a key with the same request to retry a call whose result you did not see; Nodex remembers it for seven days.
  • Command line results are short. A write reports what changed on each Page, with the values before and after, and leaves out internal detail.

Fixed10

  • Local images load more reliably on Windows.
  • A new Windows host can start a team Space. Nodex protects its settings encryption key with native Windows permissions when it creates the key.
  • A chat's composer no longer disappears. Opening a chat that finished in the background could show its messages with nothing below them while it reconnected, after its connection failed, or after its worktree was cleaned up. The composer now stays with your draft, and a line above it says what is holding the next message and offers the fix, such as Retry or Restore worktree. A chat that failed to connect also tries again on its own when you come back to it.
  • Ended background tasks clear from the Session summary after you stop an Agent. You can also use Stop to dismiss an already-ended task that still appears.
  • A heartbeat that has nothing to report stays quiet. It no longer marks its chat unread or adds to unread Automation runs, matching the notification it already skipped. Automations set to notify on failed runs only keep their successful runs quiet the same way.
Show 5 more
  • A Database no longer fails to open after a card moves into it. Moving a card to another Database without choosing a column could leave it with no Status, and the receiving Database then showed an invalid workflow status error. A moved card now keeps its Status, Status can no longer be cleared, and cards already affected are repaired to Triage.
  • Editing a card's properties updates its last-edited time, so sorting and filtering by recent edits include cards whose Status or other properties changed.
  • nodex page replace rewrites long Pages in one step and keeps unchanged blocks, with their comments and links, in place.
  • nodex page move --to page:ID works as its help describes, a move prepared for one destination cannot be applied to another, and nodex page rename takes the Page first and points out swapped arguments.
  • Command line input errors name the field that is wrong and the values allowed there, and an unknown command suggests the one you likely meant.

v0.5.5

LatestNov 11, 2026

13 added10 changed1 removed10 fixed

Added13

  • Open and edit skills as pages. Customize groups skills by folder and shows which Agents read each one. Open a skill from a chat or the command palette, edit its instructions with changes saved directly to disk, or duplicate a read-only skill to make your own copy.
  • Mention skills in Pages with $ or the Skills section of @. Click a mention to open the skill’s instructions. When you send the Page text to a chat, the mention becomes a skill invocation in the message.
  • Nodex now coordinates your chats. One long-lived Nodex conversation routes every Inbox message knowing what is already running, watches the chats it starts, and keeps your Inbox focused on waiting messages and Pages waiting for you. Nodex adds a note when a Page needs more context, and one notification follows each episode. A chat can return a misrouted message with a reason for Nodex to route again. Reply to a Page waiting for you and your words go straight to its active chat, or answer the question it asked; open Nodex from the Inbox header to talk to it directly, and turn on Start my requests to let it start what you clearly ask for without a click. Work advances through Triage, Todo, In Progress and In Review as it starts and reports; your later Status choices take precedence. Accept reviewed work with nodex page accept; canceled work retires without releasing its dependents.
  • Pages have an Owner and one Assignee, either a person or an Agent. Board cards can wait for one another, and an Agent Assignee can be set to Start automatically. Cards, List rows, the Inbox and each Page’s Status say plainly whose move a Page waits for, such as Needs your answer, Ready for Alice’s review, Codex is working, Queued · 2nd or Waiting for NODEX-2. A Page’s Status offers Start, Resume, Accept or Open chat when you can act, while your later Status choices take precedence. Start hands a card to a chat Nodex watches, a card set to Start automatically starts once the cards it waits for are done, and for a bigger request Nodex can propose a plan that creates and starts its cards in one step.
  • Each Page’s Agent work in a Git Project gets its own branch and worktree, shared by its later chats. A new chat opens with its prompt while Nodex prepares the checkout. If preparation fails, the chat shows the reason and lets you retry. The Page shows its pull request and the GitHub threads it follows, the Board shows its pull request, and completing or canceling the Page removes the idle checkout while keeping the branch and PR link.
  • Work that starts without you, such as Automations and Pages set to start automatically, waits behind a limit you choose in Agents settings, initially four, and shows its place in the queue. Your own chats and the tasks they delegate never wait.
  • Pause Agent work for a Page, a Project, or the whole Space. Running work stops while queued messages and results wait for you to resume, including across restarts.
  • Your Agents can do what you can in Nodex. Ask a chat to start, pause, resume or accept work, set a card to Start automatically, set up an Automation that runs on its own or start one waiting for you in the Inbox, and History and Activity show it acted on your behalf. By default it asks before unattended work, leaves its own work for your review and leaves work you paused alone.
  • Watch GitHub from Settings → GitHub. Choose repositories and discover assignments, review requests and mentions. Updates on followed threads reach the Page's active chat, verified PR milestones move its stage, and new GitHub requests arrive in the Inbox for your decision. Nodex can acknowledge a request and post its result back to its GitHub origin. Problems in the Inbox offer a fix, and Activity explains routing, milestones, delivery and recovery. Polling, delivery and replies resume safely after restart.
  • Work with other people in a team Space. Join one from the account menu at the bottom of the rail, then switch between Spaces there or from the command palette, moving between a team's Pages, Boards and Inbox alongside your personal Space; each Space keeps its own layout, and losing access to a team leaves personal work untouched. Settings → Spaces shows who is in the Space and which devices reach it: Owners invite people, revoke Devices, remove Members and rename the Space, and everyone links and revokes their own Devices. Remote access lets your phone and other computers reach your personal Space without sharing it. Connections pin the host's certificate and resume live after a dropped network. History records who made each change, and each person keeps their own Inbox, unread chats, pins, reminders and View preferences across devices.
  • Run a team Space on an always-on machine with nodex serve. It initializes the Space, its Owner and certificate, runs Agents, Sources and Automations without desktop windows, and keeps working while everyone's laptops are closed. Members start chats and work on the host from their desktops and phones and use hosted chats as they would their own: attach images, files and Pages, fork, open side chats and edit their last message. The person who started a chat and the Space's Owners rename, archive, compact or stop it, and questions and approvals stay with the Member entitled to answer them. Host status reports when Agents share the host account's file access.
  • Claude Fable 5.2 is available, and new Claude models appear as soon as your Claude Code offers them. Claude chats list the models your installed Claude Code offers your account, with their effort, Fast and Ultracode choices, without waiting for a Nodex update. The default Fable model and the name fable follow the Fable model Claude Code gives you; Fable 5.2 needs Claude Code 2.1.321 or newer.
  • See how an agent understood your request without going back to its chat. When you send a message and move on, the agent's opening statement, what it says it will do before it starts, appears briefly at the top of the window you are in. Point at it to read all of it, Stop the agent or Reply to correct it on the spot, or click it to open the chat. A working chat's hover card in the sidebar shows the same statement. Turn it off in Settings → General → Notifications.

Changed10

  • The Page open beside a chat is no longer sent with every message. The Composer shows it as a dashed suggestion; click it to send a link to that Page, and the Blocks you selected, with your next message, and click again to take it back. Each new message starts without it.
  • A chat without a Project now has a folder of its own from the start. Open a Terminal or Files in a new chat before sending anything, and the first message runs in that same folder. The project menu shows where the chat will work and lets you choose an existing folder instead; new folders live under Chats in your Nodex folder and are named after non-English prompts too. Once started, the chat's summary shows its folder, and Turn into project makes that folder a Project without moving anything. Deleting a chat removes its folder only when Nodex created it and it is still empty.
  • Agents hear from the tasks they delegate while they keep working. A delegated task's question or result reaches its Agent at the next pause between tools instead of after its whole reply, and Claude Code no longer stops its running tools to take one in. Waiting on one task also returns for another task's question, and answering a task that already finished says plainly that it starts follow-up work. A question the Agent leaves unanswered is handed to you.
  • The Inbox's History is now part of Activity, one timeline of everything handled in that Inbox. Each message you send to a chat, file, keep or finish is a single line beside what Nodex, your Automations and GitHub did, and All, Messages, Nodex & automations and Problems narrow it down. Expand a message's line to read it, see why it went where it did, and open its chat, return it to the Inbox, mark it done or delete it. A chat it went to shows its live state on the line while the work is under way.
  • Scheduled tasks are now Automations. Keep the same schedules, runbooks, waiting Inbox runs and history, and choose Dry run, Ask first or Run; only an Automation’s Owner, or an Agent working for them, can let it run on its own. Automations can also react to GitHub events: a dry run records each judgement and its reason, Ask first proposes work in the Owner’s Inbox, and Run starts Pages under a standing grant.
  • Nodex Mobile now links to each of your Spaces as one of your Devices, team Spaces included. Scan the code from Settings → Spaces → Link a device, switch between linked Spaces on the phone, and keep working in a team Space while its host runs, even with your laptop closed. Capture to your personal or team Inbox, start chats, answer your Page’s questions, accept reviewed work and follow chats live with every picture in them. Each Space is reachable at its local, Tailscale or DNS address over a connection pinned to that Space’s certificate, and on iPhone it tells you only about what is yours to answer, while you're away from your computer. Removing the phone’s Device ends its access immediately. Settings > Mobile is gone; link a phone you paired before again from Settings → Spaces.
  • Nodex Mobile has a menu for where you're looking. Tap the Space's avatar, or swipe right across the Inbox, to choose the Library's Inbox or any Project's, see how many messages wait in each, and switch to another linked Space. Choosing an Inbox no longer means opening the Composer first, each Space remembers the one you chose, and the Composer says which Project a thought will go to.
  • Side chats now stay with the chat they came from. Closing a side chat's tab, quitting or restarting no longer discards it: its tab comes back where you left it after a restart, a closed side chat reopens from the chat's summary, and Delete side chat in its tab menu removes it for good. Closing a side chat no longer asks for confirmation. Side chats of remote conversations remain temporary.
  • Side chat tabs and tool tabs such as Plan, Automation, Subagents and process output can be dragged like any other tab. Reorder them, move them to another tab group or the bottom panel, or drop them on a group's edge to split it; tool tabs stay in the right panel.
  • Clicking a file attached in a Page now opens it, instead of a small details popup. A file saved in the Page opens in a tab beside the Page, just like from the Page's Files list, so Markdown renders, HTML reports show as pages, and images, PDFs and media play. A linked file opens in Files. Right-click a file for Open in new tab, Save… and Copy reference, and press Enter on a selected file to open it. In Page history and other read-only previews, a file opens in a viewer that shows the version that was captured.

Removed1

  • Save as chat is gone from side chats, which now keep their conversation on their own.

Fixed10

  • On iOS 27, tapping a button in Nodex Mobile's top bar no longer also scrolls the list beneath it to the top. Opening Settings used to leave the Inbox at its oldest message.
  • Older chats open again after upgrading Nodex.
  • Dropping a tab on the edge of a tab group now splits the group instead of doing nothing.
  • Page history opens again after you edit a Page and pause. The automatic revision Nodex saves when you stop editing made the Page's history show a database error instead of its revisions.
  • Usage analytics that is off when Nodex starts no longer sends events an earlier launch left waiting. Setting DO_NOT_TRACK, or otherwise turning analytics off while Nodex was closed, now discards them as turning it off in Settings does.
Show 5 more
  • Agent settings edits through symbolic links apply reliably, including immediately after startup or after a link points to a new file.
  • A heartbeat's unread dot in Automations clears once you open its chat. It used to stay forever, because only a cron run opened from its folder was marked read. Any finished run is now read as soon as its chat is on screen, however you got there.
  • Heartbeats run on their schedule. An hourly heartbeat ran about every 90 minutes, and one set to every few minutes waited half an hour between runs, because Nodex postponed each one after its own previous run. A heartbeat now waits only while its chat is busy, and counts its interval from when the previous run started, so a long run no longer pushes the next one back. Heartbeats an hour or more apart start within five minutes either side of their time.
  • Every Agent can now set up and change Automations, reorder Sidebar Sections and manage a chat's queued messages, not only Codex. Claude Code never saw these Nodex tools, and its heartbeats now stay quiet unless something needs you.
  • Browser tools that sit over a web page show again. The annotation composer, the device toolbar's resize handles and the offer to save a password were hidden behind the page, as was the sidebar when it slid over a full-width Browser.

Added3

  • Nodex's Dock icon now shows how many chats are unread. It counts the same chats the sidebar marks unread across every Project, updates as soon as you read one anywhere, including on your phone, and clears when Nodex closes. Turn it off with Badges in Nodex's notification settings in System Settings.
  • Get Nodex Mobile from its public TestFlight beta on iPhone, or download the Android app from nodex.jyu.app/download. Every Nodex release now ships the phone app with the same version, so the phone and the computer it pairs with stay able to talk; TestFlight keeps the iPhone app current, and a newer APK installs over the old one without losing your pairing.
  • Each Nodex window is now named after what it shows, so you can tell windows apart in the Window menu, Mission Control, the Dock and window switchers. A chat window shows the chat and its Project, such as Fix flaky E2E — nodex; a Project, Page or Database window shows its name; and titles follow renames and Page title edits as they happen. On Windows the title ends with Nodex.

Changed2

  • Nodex Mobile clears notifications for chats you've already read on your computer. As soon as the app connects, and whenever your chats change while it's open, notifications for chats that are read, archived or gone from your chat list leave Notification Center.
  • Your phone now hears from Nodex only when you're away from your computer. A chat you're watching on the desktop no longer buzzes your phone. The phone is told at once when the computer's screen is locked or nobody has used it for five minutes, and otherwise only if you walk away before touching the computer again. Answering, opening the chat anywhere, or a newer notification in the same chat withdraws one that is still waiting. A chat open on your phone no longer raises a desktop notification or turns unread, and opening it there clears its desktop notifications. A locked screen counts as out of sight on the desktop too, so chats that finish while it is locked turn unread and notify as usual. Chat reminders now reach your phone as well.

Fixed2

  • Folders in the Files tree collapse again when a folder inside them is open. Previously the open folder inside kept reopening its parent; now it keeps its own state and is open again when you reopen the parent. Large folders also show a loading row until their entries arrive, and scrolling long folders no longer slows the Files panel.
  • Your phone no longer says a chat finished while it is about to continue with a queued message or delegated results, and no longer sends a finish and a question for the same moment. Phone notifications now follow exactly the same rules as desktop notifications.

v0.5.2

Nov 8, 2026

14 added14 changed25 fixed

Added14

  • A new Profile now opens on a short setup instead of a sample Project. It shows which Agents Nodex found, lets you sign in or install the ones you want, or add Nodex credits if you'd rather pay as you go, offers the projects you've already used with Codex and Claude Code, and lands on New Chat with a first task ready to send. Nothing is created until you choose it, and Run setup again in Settings replays it.
  • Insights shows what your agents did across this device, and turns it into a card you can share. Open it from the rail to see tokens, models, cost at API list price, messages, how many agents ran at once, tasks finished and Pages written, including Claude Code and Codex history from before you installed Nodex. Reading that history takes one click to allow and keeps only counts on your device. Share makes a Skyline or Receipt image to copy, save or post, with no project names or prompts on it.
  • Archiving a chat now lets you take it back. A toast appears right away: Undo restores the chat and returns you to it, and View opens your archived chats.
Show 11 more
  • Settings now shows exactly what usage analytics send. Open See what is sent in Settings → General → Privacy to read your random ID and every event waiting or sent since launch. Prompts, code, titles and file paths have no field to travel in.
  • The Codex usage ring now shows your remaining credits. Hover it to see your balance below the usage windows. When a limit is used up and credits keep you working, the ring turns amber instead of red, and the card says the credits are in use.
  • You choose which models Nodex can use in Settings → Models. An off model leaves every model menu, and nothing in Nodex can start it. Nodex credits are protected by default: only what you start can spend them, so an Agent on another provider can't start a Nodex subagent unless you allow it, and turning Nodex off means nothing on this computer can spend them.
  • Account settings now show what each Nodex model costs. Model prices lists input, cache and output prices per million tokens in credits, always current with what the service charges, so you can see what a top-up buys before you pay.
  • You can add and remove images when you edit a sent message. Its images move into the editor, where you can paste, drop or pick more and remove any of them, so a wrong screenshot no longer means starting over. An image whose file was lost shows as failed, and removing it lets the edit through.
  • Every Agent can now use the built-in Browser, your Chrome, and Computer Use: Claude Code, OpenCode, and ACP agents such as Gemini CLI, as well as Codex. Ask one to open a page, test your local app, or work in a Mac app, and Nodex asks before it runs code or reaches a new site or app. Type $ in the composer to pick one of these skills yourself, and on macOS the chat summary can show what the Agent is doing in picture in picture.
  • Nodex now has an iOS and Android app. Drop a thought into the Inbox, start a chat, follow a running chat live, and answer its approvals and questions from your phone. Turn it on and pair a phone in Settings > Mobile. It connects directly to your computer over your local network or a tailnet, encrypted end to end, and captures made offline send when your computer is back.
  • You can stop an Inbox suggestion that is taking too long. Hover its spinner and click stop: the work ends at once, no more usage is spent, and the message keeps any advice it had or offers Suggest.
  • You choose the reasoning effort and speed Inbox suggestions run at, in the same model menu new chats use. Until you do, they stay at high on Codex and medium on Claude.
  • You choose which model titles your chats in Settings → General. Until you pick one, a light model on the chat's own Agent writes the title, such as GPT-6 Luna on Codex and Haiku on Claude Code, so titles cost less on your expensive models. A model you pick receives each chat's first message, and can also title chats on Agents that can't generate text themselves.
  • A Terminal's tab names the program running in it. The title a program sets replaces the folder name while it runs, unless it only repeats the working directory.

Changed14

  • Agent activity now says what happened in plain language, naming the Pages and chats it touched instead of showing IDs. Rows read like Read Launch plan or Updated Launch plan +2 -1, every Nodex tool has one, and clicking a name opens that Page or chat. Opening a row shows the result for reading, such as the formatted Page or the diff, and hovering a Nodex or MCP tool row reveals an inspector with the exact input, output and record.
  • OpenCode models now start off, free ones included, so a new chat never lands on a third party's model unless you chose it. Turn them on during setup or in Settings → Models.
  • You can now search the conversations you import from Codex and Claude Code. Settings → Conversations lists your whole history as soon as it opens: type to find a conversation by title or folder, filter by Agent, folder or import status, and select across several searches before importing. The same field still takes a pasted link or ID, and the list and its import controls now stay on screen together however long your history is.
Show 11 more
  • New chats remember the model you last chose for one, on any Agent. Pick Claude Code, OpenCode or a Nodex model in a new chat and the next one starts there with the same effort and options, instead of going back to Codex. Switching models inside a chat you already started now stays with that chat, so it no longer changes what new chats start on.
  • Notifications stack at the top of the window. Up to three show at once and fan out when you hover them, hovering pauses their timers, and you can swipe one away.
  • Usage analytics and crash reports are now on by default, and first launch says so. Nothing is sent until you have had a minute to turn it off in Settings → General → Privacy, and turning usage analytics off takes effect at once and discards anything unsent. DO_NOT_TRACK is respected. Session replays stay off unless you enable them, and the separate web analytics setting is gone because Nodex no longer collects web analytics in the app.
  • Reviewing unsaved edits now shows exactly what they would add to the Page. Word-level changes appear in place, unchanged content folds away, and one sentence says what restoring does or that nothing was lost, so you no longer compare two full copies by eye. Edits that can't be merged can still be copied back with one click, and discarding applies immediately with Undo.
  • Agent chats now take far less disk space, and their history no longer grows without limit. A store of about 9 GB from a month of heavy use shrank to about 2.5 GB. Nodex keeps a day or two of internal activity instead of all of it, compresses command output, and no longer records hooks that finish with nothing to report. An older store upgrades once, which can pause the first Agent start after updating and a later one for a few minutes. History keeps the first and last 128 KiB of a command's output, and Hooks now appears on a reply only when a hook failed, blocked, stopped or reported something.
  • Nodex prepaid balances are now counted in credits instead of dollars, at 25 credits to $1. Your balance keeps its value and reads as a whole number, and Top up shows how many credits each amount adds.
  • The macOS installer is about 30% smaller, so first-time downloads finish sooner, and Nodex uses about 250 MB less disk space. Opening the disk image and copying Nodex to Applications take a little longer on a first install.
  • The Windows installer is about a fifth smaller, and installing it takes less disk space.
  • Full macOS updates are about 40% smaller, so updating downloads much less when an incremental update isn't available.
  • Inbox suggestions no longer wait in line behind each other. Up to five run at once, or as many as 16 if you raise the limit in Settings → Inbox, so a message that takes a while to look into doesn't hold up the ones after it, and every message waiting for advice shows its own spinner instead of only the newest one.
  • ⌘K (Ctrl+K on Windows and Linux) clears a focused Terminal. It opens the command palette everywhere else.

Fixed25

  • Agents now show the HTML pages they make as rendered pages beside the chat. Opening one used to show its source code. An Agent opening the page again reloads the same tab, so you see its edits, and it can still show you the source when you ask.
  • A chat that continues after a restart can open tabs beside it again. With several windows open, its Agent used to stop and show you nothing; it now uses the window showing that chat.
  • The marker showing that a chat moved to another Agent now stays visible. It says which Agents the chat moved between and what it carried, and it used to fold away as soon as the reply finished.
Show 22 more
  • Returning a chat to Codex keeps Codex's own conversation. A resume that had already succeeded could be thrown away because its background terminals couldn't be listed, which started a new conversation and pasted the whole history into it.
  • Fast mode now works on current Codex models. The Fast toggle, /fast, the speed setting for new chats, a scheduled task's speed and speed="fast" in a prompt's agent config had no effect or failed, because these models name the tier differently. If you turned Fast on earlier, new chats now really run at Fast and use more of your usage; turn it off in the model menu or Settings.
  • Claude Code chats no longer stop partway through a long tool call. A long script or file could end the reply and kill the command it was running; how much an Agent streams can no longer end a reply.
  • Chats woken by finished background work no longer end silently after an error. If the Agent stopped during that reply, the chat looked finished until you typed “continue”; now it recovers and carries on like any other reply, on Claude Code, OpenCode and ACP Agents.
