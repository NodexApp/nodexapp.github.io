Download for macOS
$brew install --cask junyudev/tap/nodex

Mix harnesses

Let Claude lead. Let GPT build.

A Claude Code session can fan out to GPT-6.1 Sol in Codex, keep an eye on every task, and merge what comes back — in one transcript, on your machine.
  • Any chat can hand parts of its work to another provider’s model with delegate_task.
  • Every subagent keeps its own conversation you can open, follow up on, or stop.
  • Pick per part: a frontier model where it matters, a free one where it doesn’t.

Every agent, every plan

Bring the plans you pay for. Add the free ones.

Sign in once per provider and every model is one menu away. Nodex shows how much of each plan is left, so the expensive model goes where it matters and a free one takes the rest.
  • Codex, Claude Code and OpenCode built in — plus 40+ agents from the ACP Registry, like Gemini CLI and Qwen Code.
  • OpenCode’s free models sit in the same model menu as everything else.
  • Usage meters for each account. The Inbox weighs what’s left before it picks a model.
  • Switch models mid-chat: your next message hands the conversation to the new Agent.

Pages, not transcripts

The work lands in Pages you both edit.

Every Inbox message is already a Page on your Board. Hand it to a chat and it moves from Triage to Build; agents query the Board, update properties, and write findings straight into the Page while it’s open, attaching reports, screenshots and traces that open in a tab beside it. When you’re happy, mark it done and it ships.

Agent-ready, all local

Ask once. Watch the whole board sort itself out.

Your Pages and Databases live in one local Profile built for agents. Ask in plain words, and the View you have open regroups as the edits land.
  • Agents use the nodex CLI: one read-only SQL query reads a whole View.
  • Edits land as one transaction and never overwrite newer changes.
  • Every agent Nodex runs gets the same CLI. Every change stays in Page history.
